## Other paths read

- Admin settings panel and context: save/read permissions unchanged; stabilized social-platform input focus.
- Shared SEO: removed duplicate publisher suffixes, preserved full site description within 320 characters, updated canonical links, cleared old X account.
- Static document head: default tags are owned by the dynamic head manager, so rendered pages no longer retain duplicate defaults.
- Crawler function: now uses shared rules and route registry, normalizes query strings/trailing slashes, and does not restore a removed X profile.
- Cloudflare Worker: reads crawler function output; one-hour caching and deployment remain unchanged.
- Data policies: public read and administrator-only insert/update remain unchanged. No data function or other background job generates SEO tags.
- Shared resource layout: already delegates SEO; covered by common changes.
